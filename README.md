# «Тихая сцена» — серверный MVP

Платформа реализует маршрут:

`подача работы → серверное сохранение → отзыв модератора → статус автора → следующий шаг`.

Публичная часть включает разделы «О платформе», «Эксперты», «Персональные данные» и «Авторские права», форму вопроса, заявку на включение в число экспертов и официальные ссылки учреждения. Вопросы и заявки сохраняются в закрытой базе и отображаются модератору; отдельный кабинет эксперта не входит в текущий MVP.

## Быстрый запуск в Windows

1. Один раз запустите `install_server.bat`.
2. Запустите `run_server.bat`. Скрипт попросит пароль модератора. Либо заранее задайте его в командной строке:

```bat
set MODERATOR_PASSWORD=придумайте-длинный-пароль
```

3. Если пароль был задан заранее, в той же командной строке запустите:

```bat
run_server.bat
```

4. Откройте `http://127.0.0.1:8000`.

Сервер не запускается без пароля модератора. Используйте отдельный длинный пароль и не передавайте его авторам.

## Ручной запуск

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
set MODERATOR_PASSWORD=придумайте-длинный-пароль
.venv\Scripts\python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

## Сценарий проверки

1. Откройте «Подать работу» и отправьте демонстрационный текст.
2. Сохраните выданный код вида `TS-XXXXXXXX`.
3. Откройте «Модератор», введите пароль и отправьте отзыв.
4. Откройте «Мой статус», введите код и выберите следующий шаг.
5. Проверьте формы «Задать вопрос» и «Стать экспертом» в нижней части сайта: новые обращения появятся в кабинете модератора.

## Где хранятся данные

- SQLite: `data/quiet_stage.db`;
- аудиофайлы: `data/uploads/`;
- сессия модератора: защищенная cookie браузера и хеш токена в SQLite;
- код автора: в базе сохраняется только SHA-256-хеш.
- вопросы и заявки экспертов: отдельные таблицы SQLite, доступные только через кабинет модератора.

Каталог `data` не является публичным и исключен из Git.

## Реализованная защита

- отдельный вход модератора;
- HttpOnly/SameSite cookie;
- CSRF-токен для отправки отзыва;
- случайный код доступа автора;
- ограничения длины полей;
- ограничение аудио 15 МБ;
- белый список форматов MP3/M4A/WAV/OGG;
- случайные серверные имена файлов;
- журнал ключевых действий;
- отсутствие открытых комментариев и публичного доступа к файлам.
- сервер выдает только файлы интерфейса; база, загрузки и исходный код backend не доступны как статика.
- сервер фиксирует дату и версию условий обработки данных и авторских прав;
- для группы 14–17 лет требуется отдельное подтверждение согласия законного представителя.

Текущая версия условий: `1.0-2026-09-24`. Тексты в интерфейсе являются проектом условий пилота. До приема реальных работ оператор должен утвердить их, добавить официальный контакт для обращений и провести правовую проверку.

## Перед публикацией в интернете

Этот MVP предназначен для локального тестирования. Для публичного пилота дополнительно нужны HTTPS (`COOKIE_SECURE=true`), PostgreSQL, резервное копирование, антивирусная проверка файлов, журналирование входов, ограничение частоты запросов, утвержденные формы согласий и проверка требований к персональным данным и работе с несовершеннолетними.

## Демонстрация на Vercel

Проект содержит `app.py` и `vercel.json` для развертывания FastAPI на Vercel. В serverless-среде SQLite и загрузки размещаются в `/tmp/quiet-stage`. Это временное хранилище: данные могут исчезнуть при холодном старте или переносе функции. Публичный Vercel-деплой предназначен только для демонстрации интерфейса с тестовыми данными, не для приема реальных произведений и персональных данных.
